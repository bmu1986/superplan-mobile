# SuperPlan Mobile

Веб-приложение SuperPlan для iPhone и iPad (Safari → «Поделиться» → «На экран Домой»).
Работает с той же базой, что и SuperPlan на компьютере: `superplan.db.gz` и `files/` в папке приложения Dropbox.
Данные хранятся только на устройстве (IndexedDB) и в вашем Dropbox; в этом репозитории только код.

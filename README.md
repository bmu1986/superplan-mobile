# Organizer Mobile

(До 0.5.0 называлось SuperPlan Mobile. Адрес, база и папка в Dropbox остались прежними.)

Веб-приложение Organizer для iPhone и iPad (Safari → «Поделиться» → «На экран Домой»).
Работает с той же базой, что и Organizer на компьютере: `superplan.db.gz` и `files/` в папке приложения Dropbox.
Данные хранятся только на устройстве (IndexedDB) и в вашем Dropbox; в этом репозитории только код.
